The full icon set, style B

All 70 icons both apps use, under the app's own names so they drop in one for one. They're grouped by job and drawn on the 24 grid with the rules from the icon-style page. Switch the size to see the 1 px navy offset come and go: it shows at 20 and 24 px and is left off at 16 px.

At 3x, the Flip's real pixels

Each icon drawn at 72 × 72 pixels, which is 24 dp on the Flip5 (480 dpi). Turn on Spec overlay for the 20 dp live area.

On blue, and the active state

In light theme the accent blue is the same hex as the brand navy (#1A6FE0), so a navy offset vanishes on any blue surface or blue icon. On those, the offset uses the deeper navy #0B3E85, as you decided. Active icons turn accent on the soft accent circle. Measured below: the deeper navy helps in light theme, but in dark mode the plain navy shows better on the light-blue active icon, so active icons use the deep navy in light theme only.

New in Phase 5

The surfaces the other session shipped in dev 0954022, at their real sizes. Several use icons under 16 px (12, 13, 14). Those follow the 16 px rule: no offset. Style B has one weight only, so the silent fallback to duotone that happens today (for example eye at 16 px has no bold) can't happen.
